# FMCG Sales Power BI Analysis

Power BI data analysis project covering FMCG sales, marketing, profitability, sales channels, brands, products, regions, logistics, and profit drivers.

## Project Overview

This project analyzes 18,240 FMCG orders across 2023–2025 using Power BI and DAX.

### Key figures
- Gross Sales: **$17.08M**
- Net Revenue: **$14.45M**
- Total Profit: **$3.31M**
- Orders: **18,240**
- Units Sold: **3.88M**
